Frame = SLSYNC1|sessionId|index|total|flag|chunk. Body = UTF-8 JSON → optional DEFLATE-raw (flag D) → base64 → split into ≤700-char chunks. Receiver collects all indices, reassembles, base64-decodes, inflates if D, parses JSON, and replaces the save. This companion never modifies the game file.
