Let's get connected

Agent HQ reads and writes your team roster, agent CLAUDE.md files, session, scheduler, and task-queue data directly off disk — no server, no account, nothing leaves your computer.

  1. Click Connect Data Source below.
  2. In the folder picker, choose a folder to store your team in — Agent HQ keeps everything inside a Claude/Agents subfolder there. A dedicated folder is the tidy, low-access choice. To also see live session monitoring, pick your user folder (the one containing .claude) instead.
  3. Click Allow when the browser asks for permission.

That's it — Agent HQ automatically creates the folders and a starter team of 5 agents the first time it connects. Nothing to configure by hand. Everything stays on your computer — no network, no account. Note: the browser grants read/write to the whole folder you pick, so it can create/edit files inside it; pick a folder you're comfortable with, and use Disconnect anytime to revoke access.

Welcome to Agent HQ

Your control center for a team of Claude agents — an org chart, live session monitor, and task queue, all in one place.

🔌

Connect once

Click Connect Data Source and choose a folder. Agent HQ reads and writes real files there directly — no server, no account. The first connection automatically creates a starter team of 5 agents and their instruction files.

🗂️

The org chart

The Team tab shows your agents as a chart. Click a Claude to see its details. Drag one Claude onto another to change who it reports to — valid managers light up as you drag. Scroll to zoom, drag empty space to pan.

✏️

Manage your team

Click an agent's name to rename it. Use + Add Agent to grow the team. Edit an agent's CLAUDE.md instructions or attach reference .md files right in the detail panel.

🚀

Launch & monitor

Launch in Cowork/Code gives you a ready-to-paste startup prompt for an agent. The Monitor tab shows live sessions, scheduled tasks, your task queue, and an activity feed. Click ? Help anytime to see this again.

Reset Agent HQ

Agent HQ never deletes your agent folders or CLAUDE.md files. Pick a scope, then type RESET to confirm.
